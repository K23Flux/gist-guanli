# Linux 构建

生产 Linux 构建在独立的 Linux 构建机完成。主机名、账号、路径、资源限制、镜像摘要和二进制哈希记录在私有运维记录，不写入公开源码。

## 构建输入

只上传通用构建输入：`Cargo.toml`、`Cargo.lock`、`migrations/`、`src/`、`templates/`、`static/`。不传 `var/`、`.tools/`、`master.key`、SQLite、正式域名或凭据。

## 推荐流程

1. 本地完成格式、Clippy、测试和 Windows 构建后，把源码打包传到构建机；逐文件 SHA-256 核对上传内容。
2. 在构建机的受限容器中执行 `cargo test --release --locked` 与 `cargo build --release --locked`；记录工具链、产物字节数、SHA-256 和镜像摘要。
3. 只把产物和校验值传到运行机的独立候选位置；在运行机核对哈希、备份旧二进制、安装并重启 systemd。
4. 运行生产 HTTPS 验收；构建机不向公网开放端口、不跑常驻服务。
5. 源码推送到源码仓库；服务器地址、IP 白名单、正式口令和备份路径不写入源码仓库。

## 注意

源码压缩包先写独立临时文件，解压到干净目录；执行构建脚本时从仓库目录传绝对路径，避免把脚本放进不可信压缩包目录。
